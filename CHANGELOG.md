## [0.1.0] - 2026-07-23

### Added

- Authoritative Rust engine extracted from the private Baixada Truco workspace.
- PyO3 binding and small Python development wrapper.
- Independent TypeScript engine with strict typechecking.
- Exact `truco-spec` revision lock, checksum verification, and shared
  conformance suites.
- Locked, SHA-pinned public CI and dependency update policy.
